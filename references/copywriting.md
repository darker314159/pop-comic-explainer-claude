# 文案二创：用 water-koubo 把参考稿改成抖音爆款口播

本 Skill 内置了第三方 Skill **water-koubo（爆款口播二创）**，位置：`copywriting/water-koubo/SKILL.md`。

## 什么时候用

| 用户给了什么 | 怎么做 |
|---|---|
| 一篇完整的参考稿 / 别人的爆款文案 / 文章，要"改成口播""二创""洗稿""做成视频" | **用 water-koubo**（下面的流程） |
| 只有一个主题或几个观点 | 不用 water-koubo，按 `script-writing.md` 自己写 |
| 自己写好的成稿，要求"按原文做" | 不改写，直接第 3 步 |
| 参考稿不完整（只有标题、截图看不清、链接） | 按 water-koubo 规则只回复一句：`把完整参考稿发我。` |

## 流程

**第 1 步：读规则。** 完整阅读 `copywriting/water-koubo/SKILL.md`，严格按它的 `[M01]~[M10]` 写作、`[Q01]~[Q06]` 自检。
要点（以原文为准）：只用这一篇参考稿、不联网补料；保留原段落顺序和推进关系；前 3 段加一个新增判断；
参考稿里的第一人称经历/客户/收入/数据**不能写成用户亲历**；不编造数字；结尾回应开头、不加无关的点赞关注口号。

**第 2 步：出稿并保存。** 产出严格是三段（不加任何其它内容），保存成 `projects/<名字>/script.md`：

```text
标题：越讨好，越廉价

封面文字：你越懂事，越没人心疼

口播正文：
你有没有发现，你对别人越好，别人越不珍惜你？明明随叫随到，却总被当成备胎。

……（自然口播段落，不加"开头/案例/爆点"标签）
```

如果是在对话里，先把这三段发给用户确认（用户说"直接做"就跳过确认）。

**第 3 步：转成分镜骨架。**

```bash
python3 tools/script2story.py projects/<名字>/script.md        # → projects/<名字>/story.json
```

脚本会：按标点把正文切成 ≤18 字的短句（保持原顺序）→ 每 1~3 句合成一个场景（段落边界一定断开）→
写入 `meta.topic`（顶部胶囊）/ `meta.cover`（封面文字）、轮换背景色、给每个场景放一个默认角色。
标题会写成 `【待填】`，**校验器会报错直到你全部填好**。

**第 4 步：填分镜。** 打开生成的 story.json，逐个场景：
1. `title` 换成 4~8 字结论（第 1 个场景可直接用 script.md 的"标题"或"封面文字"）；
2. 给每个场景标 1 个 `[关键词]`（不要改旁白的意思，可以微调断句）；
3. 按 `scene-recipes.md` 换掉默认角色，配主视觉 + 贴纸；
4. 然后照常 `python3 tools/make.py projects/<名字>/story.json --check`。

## 改写时要额外注意（配合本视频形式）

- 正文就是旁白，**不要写括号、emoji、英文缩写、阿拉伯数字范围**（MiMo 会把括号当语气指令；"3-5"写成"三到五"）。
- 口语化短句，逗号多一点，方便切成 8~18 字一句。
- 时长：用户没说时跟随参考稿体量；一般 45~90 秒 ≈ 250~450 字。
- 不需要"第一、第二、第三"——water-koubo 保留的是原稿的因果推进，原稿没分点就不要分点。
