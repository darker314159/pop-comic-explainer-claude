# 口播文案写作指南（先写稿，再拆分镜）

这类视频的灵魂是 **"把一个反常识的心理现象拆开讲清楚"**。画面只是帮观众看懂。文案写不好，画面再漂亮也没人看完。

## 0. 文案从哪来

- **用户给了参考稿 / 别人的爆款文案** → 先按 `references/copywriting.md` 用内置的 water-koubo 二创成抖音口播稿（标题 / 封面文字 / 口播正文），再回到本文第 5 节拆分镜。
- **用户只给了主题** → 按本文直接写稿。
- **用户给的就是自己的成稿** → 不改意思，只按第 3 节把长句切短。

## 1. 结构（不固定，跟着内容走）

**不要求"第一、第二、第三"按点论述，也不要求 PART 章节。** 爆款口播靠的是一条连贯的因果链，而不是列提纲。
写稿时只要保证下面 6 个作用都有（顺序可按内容调整，参考稿的原顺序优先）：

| 作用 | 要回答的问题 | 常见位置 |
|---|---|---|
| 开头钩子 | 观众凭什么停下来？（冲突 / 反常识 / 悬念 / 点名） | 第 1 个场景 |
| 核心判断 | 这条视频到底要证明什么？在什么条件下成立？ | 前 3 个场景 |
| 因果推进 | 为什么会这样？问题 → 原因 → 结果 → 转折 | 中段 |
| 案例证明 | 用一个具体场景/人/对话把判断"演"出来 | 中段 |
| 爆点 | 最强的认知反转或情绪释放 | 后 1/3 |
| 结尾回应 | 观众最后带走什么判断？要呼应开头 | 最后 1~2 个场景 |

- 全片 **30~150 秒**，推荐 45~90 秒。MiMo 配音约 **4~5 字/秒**，edge-tts（rate +10%）约 4.5~5 字/秒。
- 段落之间用 **转折句** 过渡，而不是"第二点"："可问题是……" / "更扎心的是……" / "说白了……" / "那怎么办？"
- **结尾不强制"关注我"**。最后一句应该是一句能被记住的结论或金句；要不要加"关注"贴纸由用户决定（贴纸可以只出现在画面上，不进旁白）。
- 只有当内容**本身就是并列清单**（"三个信号""五个习惯"）且视频较长（> 90 秒）时，才考虑用 `chapters` + PART 卡分段（见 SKILL.md "可选：章节"）。一条视频里"第一/第二/第三"出现 3 次以上，校验器会提醒你。

## 2. 开头 3 秒钩子（最重要）

第一个场景的第一句必须让人停下来。可用句式：
| 类型 | 例子 |
|---|---|
| 反常识结论 | "你搞定的女生越多，就越难心动" |
| 扎心提问 | "为什么你越懂事，越没人心疼？" |
| 具体场景 | "凌晨两点，你又打开了她的朋友圈" |
| 数字冲击 | "百分之九十的人，都在用错误的方式道歉" |
| 身份点名 | "如果你是那种从不麻烦别人的人" |

第一个场景配：大标题 + 角色夸张表情 + 一个强元素（counter 计数 / burst / avatars 一群人）。

## 3. 句子写法

- 每句 **8~18 字**，口语化，一口气能读完。长句拆开：
  - ❌ "因为你在一段又一段的关系里不断地确认自己的吸引力所以变得越来越麻木"
  - ✅ "你在一段段关系里" / "反复确认自己的[吸引力]" / "最后变得[麻木]"
- 多用 **"你"**，少用"人们/大家"。多用具体画面，少用抽象名词。
- 每个场景只讲 **一个意思**。一个场景 1~3 句。
- 每句最多 1 个 `[关键词]`，一个场景 1~2 个。关键词 = 观众需要记住的那个词（2~4 字最好）。
- 不要写：emoji、括号、英文缩写、"3-5"（写成"三到五"）、"%"（写"百分之"），配音会读错。**小米 MiMo 会把括号里的内容当成语气指令**，旁白里千万别写括号。
- 想让某一句换语气（MiMo 配音时生效）：`{"text":"你真的以为他爱你吗", "style":"冷笑，压低声音"}`。整片语气用 `meta.ttsStyle`。
- 想让配音读法和字幕不同：`{"text":"字幕写法", "say":"配音读法"}` 代替字符串。

## 4. 节奏

- 每个场景 **2.5~6 秒**（1~3 句）。超过 8 秒一定拆。
- 每 3~5 秒画面要有新东西：新贴纸出现、表情变化、换场景。
- 观点句后跟 **例子/画面**，例子后跟 **结论**："观点 → 场景化例子 → 一句话总结"。
- 结尾：**一句话结论**（标题大字）+ **金句**（反差句式："麻木换来了自由，也拿走了心动"），并回应开头的问题。

## 5. 从文案到分镜：拆分方法

1. 把稿子按句号/问号切句，每句 ≤ 18 字。
2. 按意思把 1~3 句合成一个场景。
3. 每个场景问：**这句话能"画"成什么？**
   - 讲人的感受 → 角色 + 表情变化 + 心声气泡 (`bubble style:thought`)
   - 讲对比 → `versus` 左右分屏 或 两个角色 left/right
   - 讲多个点 → `card` 清单 / 多个 tag 依次出现
   - 讲数量/程度 → `counter` / `progress` / `meter`
   - 讲对话 → `chat` 手机聊天
   - 讲"很多人" → `avatars`
   - 讲抽象概念 → `icon` 比喻（笼子=束缚 cage、天平=权衡 balance、电池=精力 battery_low、面具=伪装 mask、锁=封闭 lock）
   - 讲否定 → `cross` 打叉；肯定 → `check`
   - 讲"真相/揭露" → `spotlight` + 角色 `silhouette`，或 `icon magnifier`
4. 给每个场景想一个 4~8 字标题（结论式："她只是镜子" 比 "关于她的作用" 好）。
