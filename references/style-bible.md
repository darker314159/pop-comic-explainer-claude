# 风格圣经（为什么好看 + 不能破坏的规则）

引擎已经把风格固定好了。这份文档告诉你 **风格的规律**，让你在选颜色、摆位置、排节奏时不跑偏。

## 1. 一句话风格
> 米色网点纸 + 粗黑描边 + 平涂高饱和撞色 + 硬投影贴纸 + Q 版帅哥美女 + 逐字弹跳大标题 + 黑底白字粗字幕。像一本会动的波普漫画杂志。

## 2. 画面结构（固定，不要改）

```
y=0     ┌──────────────────────────┐
        │                          │
y≈180   │ [系列名][主题]  ▬▬▬▬▬▬ │ ← 页眉：meta.series + meta.topic 胶囊 + 右侧时间进度条（自动）
y≈255   │       大 标 题            │ ← title：黄油体，红字黑边黄投影，逐字弹出（自动）
y≈420   │       副标题              │ ← title2（可选）
y=430   │ ┄┄┄┄┄┄ 舞台区 ┄┄┄┄┄┄┄┄┄ │
        │   角色 / 道具 / 贴纸      │ ← 你只需要安排这里
y=1404  ├══════════════════════════┤ ← 字幕面板顶部彩色细线（章节色）
y≈1538  │   白色粗体字幕 [关键词黄]  │ ← lines 自动生成，≤14 字一屏
y=1920  └──────────────────────────┘
```
- `meta.series` 改页眉的系列名（"心理拆解""情感课""职场真相"…，≤ 4 字）。
- `meta.header:false` 去掉页眉；`meta.subtitles:false` 去掉字幕；`meta.watermark:"@账号"` 加水印。

## 3. 调色板

| 名称 | 色值 | 用途 |
|---|---|---|
| cream | #f4ecdf | 默认纸张底色 |
| yellow | #ffd21f | 主强调色：贴纸、高亮、计数、光芒背景 |
| red | #e8412c | 标题、警告、印章、错误 |
| pink / rose | #ff5fa2 / #ff4f7a | 恋爱、心动、女生相关 |
| blue / sky / cobalt | #7ec8ff / #8fd6ff / #2f5fd0 | 冷静、理性、男生相关 |
| green / mint / lime | #4fd08a / #9ff0c8 / #c8f04a | 正确、自由、成长 |
| purple | #b48cff | 神秘、内心、情绪 |
| orange | #ff6a3d | 焦虑、热烈、紧迫 |
| black / dark / navy | #1c1a1f / #1f1d22 / #232a3f | 描边、深夜、真相 |
| white / grey | #ffffff / #8a8790 | 中性贴纸 / 过去、无效 |

**配色规则**
- 一个场景 **最多 3 种强调色**（不算黑白米）。
- 贴纸颜色要和背景 **反差**：浅底用 yellow/red/pink/blue 贴纸；彩色底用 white/yellow/black 贴纸。黄底不要黄贴纸。
- 同义同色：全片"正面"用 green/yellow，"负面"用 red/grey，"她/恋爱"用 pink，保持一致。
- 字幕面板边框颜色按场景自动轮换（blue → pink → yellow → green → purple…）；用了可选的 chapters 时按章节轮换，可在 chapters 里写 `"color"` 覆盖。

## 4. 背景轮换

| 背景 | 情绪 |
|---|---|
| `cream` `cream-blue` `cream-yellow` `paper` | 默认讲述（占 50%） |
| `light-pink` `light-blue` `light-green` `light-yellow` | 轻情绪、换口气（占 25%） |
| `yellow` `pink` `blue` `orange` `purple` `green` `red` + `rays`/`sun` | 高潮、金句、结论、开心（占 20%） |
| `dark` `navy` | 真相、深夜、孤独、压抑（≤ 2 个场景） |

规则：**相邻场景背景不同**（同一个 cream 系列连续 2 次可以，3 次就换）。`sun` 用于总结/高光，`rays` 用于冲击/转折。

**场景插画 `set` vs 纯色 `bg`**：
- 文案里有具体地点/时间（深夜、办公室、约会、下雨、路口、海边…）→ 用 `set`，让观众"进入故事"。插画同样是粗黑描边 + 平涂色，与角色风格统一，顶部有淡色雾层保证标题清晰。
- 观点、结论、爆点、金句 → 用纯色 `bg`（`rays`/`sun`），让文字和道具更突出。
- 推荐节奏：set 与纯色 bg 交替，约 1/3~1/2 场景用 set；同一个 set 最多连续 2 个场景（第 2 个可 `flip:true` 换机位）。
- 前景太乱时 `"set":{"name":"party","dim":0.35}` 压暗背景。深色 set（bedroom_night city_night rain_window stage）自动使用浅色字。

## 5. 字体（自动，不用管）
- 标题：站酷庆科黄油体（圆胖手写感）
- 字幕/贴纸：思源黑体 Black
- 英文数字：Archivo Black；拟声词：Bangers；可选：得意黑斜体 `smiley`、快乐体 `cute`

## 6. 构图规则
1. **一个主视觉 + 2~3 个辅助元素**。主视觉占舞台面积 40~70%。
2. **三分法**：单角色放中间时，贴纸放左右两侧（mid-left / mid-right / head-left / head-right）；双角色时贴纸放各自头顶或胸前。
3. **脸是神圣的**：任何东西都不能盖住角色的眼睛和嘴。
4. **留白**：舞台四角至少空 2 个；元素离画面左右边缘 ≥ 40px。
5. **大小对比**：主视觉要大（角色 L、图标 400+、卡片 700+ 宽），贴纸要小（字号 36~46）。
6. **斜一点更活泼**：贴纸默认会随机歪 -4~4°；印章 rot -10~-15；不要把所有东西都摆得很正。

## 7. 动效语法（时间安排）
- 场景开始 0~0.3s：主视觉入场（角色 rise、道具 pop/drop）。
- 每句旁白开始时（`L2` `L3`）：出一个新元素。
- 关键词时刻（`w:关键词`）：最重要的贴纸/印章/表情变化 + 可选 `punch`。
- 同一时刻最多 2 个元素一起出现；否则用 `+0.3` 错开。
- 冲击三件套 `punch` `shake` `flash`：全片合计 ≤ 5 次，留给真正的"高潮"。
- `loop` 只给 1~2 个元素（float 漂浮、pulse 呼吸、heartbeat 心跳、wiggle 摇摆），全部都动会乱。
- 转场：默认就很好（开头斜切、其余硬切；可选的 PART 卡用黑黄条纹）。最多再加 1~2 个 `flash`/`zoom`。

## 8. 节奏
- 场景 2.5~6s；全片 30~150s（推荐 45~90s）。
- 每 3~5 秒必须有新的视觉变化（新元素 / 表情变化 / 换场景）。
- 音效、BGM、音量标准化（-14 LUFS）全部自动。BGM：`auto`/`pop_bounce`（轻快）、`lofi_chill`（温柔/治愈）、`tension`（悬疑/真相）、`none`，或自己的 mp3 路径。

## 9. 不要做的事 ❌
- ❌ 标题写成长句（>10 字）或和字幕一模一样
- ❌ 一个场景塞 6 个以上元素 / 4 个以上贴纸
- ❌ 所有元素 `at:0` 一起蹦出来
- ❌ 贴纸压在脸上、压住标题、伸进字幕面板（y>1404）
- ❌ 连续 3 个场景同背景同角色同姿势
- ❌ 每个场景都用 punch/shake
- ❌ 在旁白里写 emoji、英文缩写、"3-5" 这种配音会读错的内容
- ❌ 修改 engine/ 里的代码来"调样式"——只改 story.json
